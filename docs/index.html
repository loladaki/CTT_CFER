Como adicionar encomendas?
  1. Edita o ficheiro data/tracking_numbers.txt no repositório (um número por linha, com descrição opcional a seguir a ;), ou
  2. No GitHub, vai a Actions → Adicionar encomenda → Run workflow e escreve o número, ou
  3. Localmente: python scripts/add_parcel.py RR123456789PT "descrição"

A atualização corre automaticamente todos os dias. Também podes forçar em Actions → Atualização diária CTT → Run workflow.
